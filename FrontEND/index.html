2. Chassis number

Find model (PartSouq) ↗ Japan history (CAR VX) ↗
Find model (PartSouq): a Japanese chassis number (e.g. LA300A-1036682) shows the model, grade, engine, colour code and production period (Toyota, Lexus, Nissan, Honda, Suzuki, Mazda, Mitsubishi, Subaru, Isuzu…; some old trucks are not listed). A 17-character VIN of a US-market vehicle is decoded here with Decode VIN. Auction / mileage history: copy the number and search it on CAR VX (free search, paid report). Recall check: the maker's own Japanese site shows the car name and its recalls / service campaigns (vehicles sold in Japan only; use the browser's Translate). Honda and Suzuki open their search page with the number copied: paste it there.

Select the make, model and year, then tap Check to see a price summary of current ads on ikman.lk and riyasewana.com.
