# APCal — 4W Leasing Calculator

APCal is a standalone four-wheel vehicle leasing calculator. Its interface follows the supplied screenshot: one Facility Details card, monthly rental summary inside the card, editable bullet payments, and a rental schedule. The theme uses red, black, and white.

## Run locally

Open `index.html` in a browser.

## Publish

This repository publishes to https://drcjayawardena.github.io/APCal/ using the GitHub Pages workflow in `.github/workflows/pages-deploy.yml`.

Default calculation inputs follow the spreadsheet's `4W` tab. Enter a bullet payment month and amount; the monthly rental recalculates and the payment appears in that month's rental schedule.
